## 🏢 General & Product

**Q: Is DsSync Hub completely open-source?**
Yes! The entire core product is free to use, modify, and host. It is designed to be a self-hosted alternative for team collaboration.

**Q: Do I need a credit card to use the Video Conferencing feature?**
No. We integrate Jitsi Meet via a secure iframe embed (`meet.jit.si`). It requires absolutely no account, no API key, and no credit card to launch High-Definition video rooms.

## 🧠 Architectural Decisions

**Q: Why use a Node/Express Monolith instead of Next.js API Routes?**
While Next.js is fantastic for Server-Side Rendering (SSR), a decoupled Express monolith was deliberately chosen to handle the massive volume of real-time WebSocket traffic. Socket.io requires persistent server connections, which conflicts with the stateless, serverless nature of Next.js API routes on platforms like Vercel.

**Q: Why Redux Toolkit instead of Zustand or Context API?**
For a simple application, Zustand is faster to set up. However, DsSync Hub manages 16 highly complex data domains (Auth, Workspaces, Chat, Real-time Tasks). Redux Toolkit provides strict unidirectional data flow, immutability guarantees, and the Redux DevTools extension, which is critical for debugging race conditions between HTTP responses and Socket broadcasts.

**Q: Can I swap MongoDB for PostgreSQL?**
Not without a significant architectural rewrite. DsSync Hub heavily leverages Mongoose schemas and NoSQL document structures—especially for the dynamic JSON payloads generated by the rich-text Note editor and nested chat replies.

## 🛠️ Troubleshooting & Dev

**Q: Why is my frontend failing to connect to the backend locally?**
Ensure your `VITE_API_URL` exactly matches the URL where your backend is hosted (including the `/api` suffix). Additionally, check that the `CLIENT_URL` inside your backend's `.env` exactly matches your frontend domain (e.g., `http://localhost:5173`) to satisfy CORS policies.

**Q: My Razorpay Payment Popup won't open. Why?**
If the modal fails to launch, the React application is likely missing the `VITE_RAZORPAY_KEY_ID` in the client environment.

## 💳 Billing & Third-Party

**Q: How do I test Razorpay integrations without spending real money?**
Use your Razorpay `rzp_test_...` keys. When the modal pops up locally or in a staging environment, you can use the official dummy cards provided by Razorpay to simulate a successful transaction and test the webhook handlers.

**Q: What happens if the Groq AI API goes down?**
The backend utilizes an "Assume Failure" pattern. The AI service rotates through fallback keys, enforces a strict 12-second hard timeout, and fails gracefully. Your UI will never permanently freeze waiting for a response.
