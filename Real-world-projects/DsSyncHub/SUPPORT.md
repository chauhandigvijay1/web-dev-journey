## 📋 Scope of Support

DsSync Hub is provided as an open-source project. To keep our maintainers focused on building features, we adhere to the following support boundaries:

### What We Support ✅
- Bugs or crashes in the latest `main` branch.
- Issues with the standard deployment flow (Render + Vercel + MongoDB Atlas).
- Clarifications on missing or outdated documentation.

### What We Do Not Support ❌
- Issues running heavily modified forks of the repository.
- General programming tutorials (e.g., teaching React, Express, or Redux concepts).
- Highly customized local deployment environments (e.g., custom Docker compose networking issues unrelated to the core app).

## 🐛 Bug Reporting Protocol

If you encounter a bug, please ensure you check the existing [Issues](https://github.com/chauhandigvijay1/web-dev-journey/issues) to avoid duplicates. 

When opening a new bug report, you **must** include:
1. **Environment Details**: Your OS, Node.js version, and Browser.
2. **Steps to Reproduce**: A clear, numbered list of actions that trigger the bug.
3. **Expected vs Actual Behavior**: What you thought would happen vs what actually happened.
4. **Logs**: Any relevant console errors from the browser DevTools or terminal stack traces.

*Issues opened without reproduction steps may be closed automatically to keep the backlog manageable.*
